# PLANT FIT 로컬 첫 버전

Windows에서 `PlantFit.exe`를 더블클릭하면 기본 브라우저에서 `http://127.0.0.1:4187/`이 열립니다. 실행 창을 닫으면 서버가 종료됩니다. 실행 파일에 화면과 엑셀 양식이 포함되어 있으며 Java, Node.js, DB, 도메인이 필요하지 않습니다. 기본 브라우저에서 로컬 저장을 허용해야 내 식물이 유지됩니다. 같은 브라우저 프로필을 사용하세요.

- **내 식물**이 시작 화면입니다. 직접 추가하거나 도감에서 찾을 수 있으며 목록은 한 페이지에 8개씩 표시됩니다.
- **식물 도감**에서 초기 예시 20종과 첨부 관리표 43개를 선택하고 이름·학명으로 검색합니다. 식물 종류로 좁힐 수 있으며, 계절을 고르면 해당 계절의 실내 점검 안내를 볼 수 있습니다. 식물 이름을 누르면 앱 안에서 관리 안내를 확인할 수 있습니다.
- **식물 추가**에서 이름, 학명, 화분 별명, 실제 위치, 계절별 성장, 관리 코드 및 추천 장소를 입력합니다. 같은 종류의 화분도 여러 개 등록할 수 있습니다.
- **내 식물**에서 등록한 화분을 수정하거나 삭제합니다.
- 화분 이름을 누르면 최근 물주기, 다음 관리 예정일, 계절별 기준과 추천 장소를 확인합니다. 오늘 물주기를 기록하거나 수정 화면에서 과거 날짜와 기준을 직접 입력할 수 있습니다.
- **관리 달력**에서 날짜를 선택하고 화분별 관리 완료를 체크합니다. 관리 항목의 예정일이 되면 빨간 느낌표가 표시됩니다.
- **관리 → 항목·주기 설정**에서 화분별 기본 관리 10개와 사용자 지정 항목을 켜고, 간격을 일 단위로 지정합니다. 작업 완료나 필요 여부 확인을 기록하면 다음 예정일을 계산합니다. 확인 후 생략은 실제 완료 이력에 포함하지 않습니다. 알림은 앱 목록과 달력에 표시됩니다.
- 최초 관리 일정은 식물 등록일부터 계산합니다. 물주기 완료는 확인 버튼을 눌러 저장합니다. 사용자 지정 항목을 삭제해도 과거 완료 기록은 유지됩니다. 화분 상세는 별도 주소로 열리며 왼쪽 **내 식물**로 돌아갈 수 있습니다.
- **엑셀 양식**에서 빈 식물 입력표, 원본 장소 A~E와 작성 안내가 들어 있는 통합 문서를 받습니다.
- 채운 양식을 올리면 식물 추가의 이름 선택 목록에 반영되고, 선택한 행의 관리 코드가 기본값으로 입력됩니다. 학명은 비워 두거나 열을 삭제할 수 있습니다. 다시 올리면 가져온 선택 목록이 갱신됩니다. 이미 등록한 화분은 유지됩니다.
- 화분 상세 대시보드에는 현재 상태, 관리, 성장, 관리조건 탭이 있습니다. 현재 상태에서 실제 기록과 최근 활동, 이번 달 성장 추이, 대표 사진, 다음 할 일을 한눈에 봅니다. 물주기는 일일 체크와 연결됩니다. 날짜별 성장 기록에는 사진·높이·잎 수·열매 수를 넣을 수 있고, 월간 리포트에서 변화와 관리 기록을 확인합니다.

가져온 식물명과 학명은 첨부 파일의 표기이며 원본의 빈 관리 조건은 그대로 비어 있습니다. 초기 도감은 공개 재배 자료를 참고한 예시 목록입니다. 전국 재배량 순위 자료는 확인되지 않았습니다.

## 개발 및 검증

Windows에서는 `Open-PlantFit.cmd`를 더블클릭하면 로컬 서버를 시작하고 Chrome에서 `http://127.0.0.1:4187/`을 엽니다. 서버는 이 컴퓨터에서만 접속할 수 있습니다. 명령줄에서는 `node outputs/plant-fit/serve.mjs`로 실행합니다. EXE와 Node 서버는 같은 포트에서 동시에 시작할 수 없습니다. 같은 주소와 Chrome 프로필에서 기존 데이터를 확인할 수 있습니다.

실행 파일을 다시 빌드하려면 이 폴더에서 아래 PowerShell 명령을 실행합니다.

```powershell
$compiler = Join-Path $env:WINDIR 'Microsoft.NET/Framework64/v4.0.30319/csc.exe'
& $compiler /nologo /target:exe /optimize+ /out:PlantFit.exe /resource:index.html /resource:app.js /resource:catalog.js /resource:original-data.js /resource:style.css /resource:plant-fit-template.xlsx /resource:workbook.js /resource:photos.js /resource:growth.js /resource:care.js /resource:jszip.min.js /resource:JSZip-LICENSE.markdown Launcher.cs
```

서버를 켠 상태에서 `node verify.mjs`로 도감 개수와 실행 파일 내장 양식의 다운로드를 검증합니다. 브라우저 검증도 수행하려면 Playwright가 들어 있는 경로를 `PLANT_FIT_DEPENDENCIES`, Chrome 실행 파일 경로를 `PLANT_FIT_BROWSER`에 설정합니다.

현재 버전은 사진과 기록을 브라우저에 저장합니다. 계정과 서버 DB, 저장 데이터 내보내기, 기상 연동과 연간 성장 분석은 후속 단계입니다.
